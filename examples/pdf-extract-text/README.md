## Capabilities

### `pdf.extract_text`

Extract plain text from a PDF file in the agent's workspace, with page count and truncation info.

**When to use:**
Use pdf.extract_text when an agent needs to read or reason over the text
content of a PDF already present in its workspace — e.g. "summarise this
contract", "what does page 2 say".

Typical: pdf.extract_text(path='report.pdf') then summarise the returned text.

Do NOT use pdf.extract_text on scanned / image-only PDFs — pages without a
text layer return empty; use an OCR capability instead.
Do NOT use it to fetch a PDF from the internet — download it first with a
network capability, then pass the local path here.

**Permission tier:** `autonomous`

#### Inputs

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `path` | String | Yes | Path to a PDF file in the workspace (absolute, or relative to the workspace root). |
| `max_pages` | Integer | No | Maximum pages to extract. Default 0 = all pages. Clamped to 1000. |

#### Outputs

| Name | Type | Description |
|------|------|-------------|
| `text` | String | Extracted text; pages joined with a form-feed (\f) separator. |
| `page_count` | Integer | Total pages in the document. |
| `pages_extracted` | Integer | Pages actually extracted (< page_count when max_pages is set). |
| `char_count` | Integer | Length of the returned text — agent need not call len(). |
| `truncated` | Boolean | True if max_pages stopped extraction before the last page. |

#### Usage Examples

**Read and summarise a whole PDF:**
```
pdf.extract_text(path='paper.pdf')
summarise the returned `text`
```

**Read only the first pages of a large PDF:**
```
pdf.extract_text(path='book.pdf', max_pages=10)
check `truncated` to know whether more pages remain
```

#### Errors

| Type | Description | Recovery |
|------|-------------|----------|
| `InvalidPath` | The path does not exist, is not a file, or is not a .pdf. | Path is wrong. Do not retry the same path; verify the file exists in the workspace. |
| `ParseFailed` | The file exists but could not be parsed as a PDF (corrupt or not a PDF). | Not a valid PDF — do not retry the same bytes. If it is actually plain text or HTML, read it with a text/file capability instead; if it was downloaded, the file may be truncated — re-fetch it. |
